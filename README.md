# ЛУК.AI — AI-стилист

Лендинг + рабочая демка подбора образов из личного гардероба.

## Структура

```
luk-ai/
├── index.html      # разметка страницы
├── css/
│   └── style.css   # все стили, дизайн-система через CSS-переменные в :root
└── js/
    └── app.js       # логика демки: гардероб, загрузка вещей, подбор образа
```

## Дизайн-система (css/style.css, :root)

- `--black` / `--black-soft` / `--panel` — фоны
- `--lime` — акцентный кислотно-лаймовый (бренд-цвет)
- `--white` / `--grey` — текст
- `--line` — границы/разделители

## Текущий функционал (js/app.js)

- Добавление вещей в гардероб: кнопками-заготовками (тип+цвет) или загрузкой своего фото
- Хранение гардероба в переменной `wardrobe` (массив объектов `{type, color, label, img}`) — **только в памяти браузера, не сохраняется между визитами**
- Подбор образа: простая случайная выборка по типу вещи (верх/низ/верхняя одежда/обувь) с учётом погоды и повода — сейчас без реального ИИ, это заглушка логики
